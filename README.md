# Ballesta Condominio — Landing Page

Landing page comercial responsiva para **Ballesta Condominio**, desarrollo residencial de Construcciones Aryve en Querétaro, México. Sitio de una sola página (one-page) enfocado en conversión: presenta el desarrollo, sus amenidades, el prototipo de casa disponible, ubicación y un formulario de contacto para agendar visitas.

**Demo en vivo:** https://damian-aguilera.github.io/ballesta/

## Características

- Diseño responsivo (mobile-first) adaptado a escritorio, tablet y móvil.
- Navegación por anclas a las secciones: Nosotros, Galería, Amenidades, Prototipo, Ubicación y Contacto.
- Galería de imágenes del desarrollo y fachadas.
- Sección de prototipo con ficha técnica (dimensiones, distribución por planta, m² de construcción).
- Mapa embebido (Google Maps) con la ubicación del desarrollo y puntos de interés cercanos.
- Sección de testimonios de residentes.
- Formulario de contacto conectado a WhatsApp Business para atención inmediata.
- Optimización básica de SEO on-page (meta description, jerarquía de encabezados, texto alternativo en imágenes).

## Stack técnico

- HTML5
- CSS3 (diseño responsivo, animaciones de transición)
- JavaScript
- Hospedado en GitHub Pages

## Contexto del proyecto

El sitio fue desarrollado a partir de un análisis comparativo de UX/UI y SEO contra el sitio oficial del desarrollo, con el objetivo de mejorar la claridad de la información (amenidades reales, dirección exacta, opciones de pago/crédito y especificaciones del Prototipo Arezzo) y la experiencia de navegación.

## Cómo correrlo localmente

```bash
git clone https://github.com/Damian7777777777/ballesta.git
cd ballesta
# Abre index.html directo en el navegador,
```
